선택 모델의 TN/FP/FN/TP는 105/61/38/76이다. 오탐과 형상 오차가 여전히 크다. 0.85에 도달한 모델이 아니며 Public 개선도 아직 입증되지 않았다.

## 확인한 원인과 변경

- 기존 검증 43장 모두 원본 영상 범위 일부가 학습 영상과 겹쳤다. 실제 256px 패치의 지리 범위로 다시 계산해도 **24/43장**이 학습 패치와 겹쳤다. 다른 촬영 날짜도 같은 지역으로 취급했다.
- 새 검증은 인접한 7개 원본 타일 지역을 통째로 보류하고 학습과 30m 완충 구역을 둔다. 실제 TIFF 영상 범위로 학습/검증 겹침이 없는지 검사했다.
- 숫자 코드 80이 산림과 쓰레기에 중복 사용된다. `ANN_NM`이 해안쓰레기로 시작하는 JSON 폴리곤만 지리좌표로 영상에 그린다. 내부 구멍은 제외한다.
- 원본의 0.1m 영상을 0.3m로 축소한다. 검증은 정답 위치와 무관한 고정 네 모서리에서 자른다. 학습에서는 무작위 크기·위치·회전·반전·색감·흐림을 적용하고 일부 양성 샘플에 쓰레기가 들어오도록 하되 위치는 무작위로 둔다.
- 50픽셀 미만의 **정답**을 검증에서 버리지 않는다. 공식 50픽셀 규칙은 **예측**에만 적용한다.

## 실험 조건

기존 보유 Validation 자료에서 학습 영상 594장(양성 77장), 검증 영상 70장(양성 39장)을 구성했다. 검증은 고정 크롭 280장 중 양성 114장이다. 크롭끼리 겹치고 같은 장소의 여러 촬영 날짜가 있으므로 280개의 독립 표본이 아니다. 이 한 지역에서 모델을 선택했으므로 독립 테스트도 아니다.

제공 원본 UNet-ResNet18에서 시작했다. 과거 AIHub 학습 가중치는 새 검증 지역을 이미 보았을 수 있어 초기화에 사용하지 않았다. CPU 4스레드, seed 20260927, epoch당 균형 샘플 256개, batch 8, 총 4회 학습했다. CE 가중치 [1,30] + Dice, encoder LR 2e-5 / decoder LR 3e-4, cosine 감쇠를 사용했다. 처음 2회는 decoder를 학습하고 이후 encoder도 갱신했다. encoder BatchNorm 통계는 고정하고 decoder 통계는 실제 영상에 맞춰 갱신했다. TTA는 이 CPU 후보에는 적용하지 않았다.

별도의 첫 시도는 decoder BatchNorm까지 고정해 모든 양성을 놓쳤다. `experiment_spatial_cpu`에 실패 기록을 보존했으며 제출 후보로 채택하지 않았다.

최종 Colab 코드에는 가장자리의 작은 마스크 보존을 위한 `INTER_NEAREST_EXACT`, 데이터 해시 기반 재개 검증, 최적 확률 파일만 보관하는 수정도 반영했다. 이 CPU 실험은 해당 세 수정 전에 실행되었다. Colab 기본 학습은 30회, epoch당 512개, batch 16이며 실제 GPU 실행은 아직 하지 않았다.
